# WPQR Standards Manager – GitHub Pages

Dette er mobilutgaven v16 pakket for GitHub Pages. `index.html` er startsiden.

## Publisering
1. Opprett en konto på https://github.com/ og bekreft e-postadressen.
2. Opprett et nytt **Public** repository, for eksempel `wpqr-manager`.
3. Velg **Add file → Upload files** i repositoryet. Last opp `index.html`, `manifest.webmanifest` og `.nojekyll` fra denne pakken (du må pakke ut ZIP-filen først). Trykk **Commit changes**.
4. Gå til **Settings → Pages**. Under **Build and deployment**, velg **Deploy from a branch**, deretter **main** og **/(root)**. Lagre.
5. Vent til GitHub viser nettadressen. Den vil vanligvis være `https://BRUKERNAVN.github.io/wpqr-manager/`.
6. Åpne nettadressen i Safari på iPhone. Velg **Del → Legg til på Hjem-skjerm**.

## Viktig
- GitHub Pages er offentlig hosting. Ikke legg inn interne WPQR-dokumenter, personopplysninger eller konfidensielle data i filene du publiserer.
- Appen bruker nettleserens lokale lagring; data følger ikke automatisk mellom PC og mobil.
- Kravmotoren er en prototype og ikke fullstendig validert mot alle gjeldende standardutgaver. Bruk originalstandarder ved formelle beslutninger.
- Oppdater appen ved å erstatte `index.html` med en nyere versjon og commite endringen.
